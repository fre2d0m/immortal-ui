## 渲染器盘点

检查 `registry/immortal` 和 `src` 的实际实现，没有发现使用 HTML Canvas 2D 或 WebGL 绘制数据图的代码。主要问题发生在自绘 SVG、容器尺寸和信息组织上；更换渲染方式本身不能替代设计。

| 位置 | 原有问题 / 边界 | 本轮处理 |
| --- | --- | --- |
| `telemetry-chart.tsx` | 固定 viewBox 的分析图被拉伸，轴过于简略，图例和说明争夺注意力 | 使用内部 `telemetry-plot.tsx` 的 Recharts 响应式坐标与折线；实际时间定位、统一尺度、分段断线、质量标记仍由数据契约决定 |
| `telemetry-explorer.tsx` | 默认展开的大查询区与重复标题挤压图表 | 有首屏结果时收起查询区；保留查询摘要，图表、时间、读数按阅读顺序排列 |
| `internal/telemetry-sparkline.tsx` | 过低的概览区、重复时间与口径文字 | 增加概览高度，时间范围压缩重复日期，详细口径可展开；保留轻量数据驱动 SVG |
| `internal/data-card.tsx` | 主值的横向滚动设置导致纵向滚动条；字框过紧 | 修正行高与溢出方向，保持长数值可横向读取。正常值不再出现滚动条 |
| `daily-histogram.tsx` / `CatalogVisual.tsx` | 时段条形与目录能量图缺少一致的视觉编码 | 统一分类色；能量封面用零基线 HTML 条形、上限与时刻标签，合计由数据计算 |
| 量程轨道 / 土壤剖面 | HTML/CSS 位置图，适合当前任务 | 保留实际量程、深度、缺测与未知位置表达；纳入窄屏检查 |
| 工作流 / 工作流目录封面 | ReactFlow 拓扑及标明静态示意的 SVG | 本轮没有替换工作流引擎；代码中的 `canvas` 变量是 ReactFlow 实例引用 |

首页、温室、设备页面和 Theme 预览通过实际组件或共享渲染能力获得更新。演示记录仍位于展示层，不加入安装依赖。

## 视觉与交互改动

- 同单位序列使用共同纵轴。图线采用稳定颜色和线型，默认色板在实际深浅面板背景上测量。浅色最小图线对比度 4.73:1，深色最小 6.56:1；图表辅助文字分别为 5.49:1、5.85:1。这不是所有自定义主题的合规承诺。
- 历史图按容器保留 224–288px 高度，坐标与标记不再随固定 viewBox 被非等比拉伸。时间轴显示窗口内的刻度，完整日期与时区留在图上方。
- 读数常驻图下，显示实际采样时间。上一点、下一点按钮始终可用，滑块与详细说明放在展开区；数据表继续提供等效核查路径。
- 默认查询区仅占一行摘要，有需要时再展开。已应用查询与未提交的表单草稿仍分开，导出沿用已应用查询。
- 图表库仅随分析图按需加载。生产构建的主文件为 484.12 kB，图表分块为 361.45 kB（gzip 101.98 kB）；这里只记录产物大小，未据此宣称加载性能或大数据能力。

采用 [Recharts 官方 LineChart](https://recharts.github.io/en-US/api/LineChart/) 的布局、坐标、参考线与折线能力。组件新增 `recharts@^3.10.1` 安装依赖，小型卡片不因这次更改引入该依赖。
