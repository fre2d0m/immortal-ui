# 工作流完整交互审查 · 2026-11-13

范围为可安装 `data-workflow` Block、共享工作流辅助组件、连线规划及相同组件的展示页。审查按“从空画布建立流程 → 分支与汇合 → 调整配置与连接 → 校验与测试 → 追溯结果”进行。没有增加 Panel 层级、常驻节点库或第二套视觉材质。

## 发现与修复

| 区域 | 问题及影响 | 处理结果 |
| --- | --- | --- |
| 画布与配置 | 原配置栏覆盖画布；实际选中汇合节点完全落在右栏下。窄屏缩放栏相对整个工作区定位，会落到配置内容上。 | 配置/问题栏占独立空间，画布按剩余宽度工作；选中节点移入可见范围。窄屏配置下排；历史、缩放工具栏放回画布内部定位。 |
| 节点 | 固定偏移复制可能叠在已有节点上；键盘缺少对应编辑路径。 | 复制复用节点避让算法，保留参数、不复制连线；补齐 Ctrl/⌘ D、Delete/Backspace，输入框内仍执行文本编辑。删除关联边与节点为一个撤销步骤。 |
| 节点信息 | 已有紧凑高度、类型/名称/关键配置分层需要保持，不能重回大面积空白或自由拼接配置。 | 保留 232px 宽度和按实际内容增长的高度；摘要继续由适配器按稳定字段生成。当前改动没有重写这一契约。 |
| 连线编辑 | 详情只有只读信息、单侧定位与删除，不能完成文档宣称的来源/出口/目标编辑。 | 详情提供“来源与输出”和“目标节点”；选择来源时明确指定出口，避免自动选择条件分支。定位图标放在对应字段旁。 |
| 连线重接 | 默认重接命中区被节点的 40px 端点命中区及加号覆盖；仅启用库选项仍无法实际拖动。 | 选中连线后显示并抬高独立圆形重接手柄；无效拖放保留原线。修改保留边标识，并仅写入定义字段，不把 React Flow 展示属性写入业务定义。 |
| 插入步骤 | 并行端点用于追加分支，缺少针对某一条分支的插入动作。 | 右键该连线插入，只替换选中边；两个新连接作为一次操作校验、提交和撤销，兄弟分支保持不变。 |
| 右键菜单 | 画布、节点、连线缺少就近操作入口。 | 分别提供画布/视图、节点、连接动作；只读隐藏变更动作，运行期间禁用变更，执行数据入口只在有相应运行上下文时提供。 |
| 工具栏 | 每个图标各占一个 Tab 停靠点；空画布适配和缩放边界仍可点击。 | 工具栏采用单个 Tab 入口与方向键/Home/End；空画布适配禁用，缩放在 15%/180% 正确禁用；提供恢复 100%。 |
| 弹层与焦点 | 更多菜单打开设置后会抢回焦点；旧菜单关闭的延迟回调可能关闭刚打开的新菜单；自动平移可能关闭刚打开的菜单。 | 操作在菜单关闭后交接；旧实例回调不影响当前弹层；用户平移关闭菜单，程序定位不误关。Escape 返回原对象，弹层优先于展开工作区关闭。 |
| 视觉状态 | 悬停、选中、键盘焦点必须保持不同职责。 | 复用 Graphite 菜单平面高亮与工具按钮材质；连线悬停 2px、选中 2.5px；保留 Tabs 单个选中表面，未选中悬停无凸起背景。 |

修复前的实际几何：画布宽 1065px，配置栏从 x=1163 开始；选中汇合节点处于 x=1255.86–1422.94，被配置栏覆盖。记录在 `outputs/data-workflow-audit-20261113/before.json`；修复后的画布、配置栏与选中节点边界由 `checks.json` 再次核对。
