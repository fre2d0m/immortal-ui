# 首批物联网组件实现与验收

首批 12 个组件已完成本地实现，包括 7 个既有组件的升级和 5 个新组件。Components 按六类界面组织；Theme 增加按组件分类的配置，并让默认行控件跟随同一尺寸基准。保留已确认的 Graphite 面板、凹陷区域、按钮及 Tabs 材质。

实现依据为 [领域研究](iot-visual-components-research-2026-11-04.md) 中的首批清单。浏览器中的设备、回执和告警均为标注的本地演示数据；本次验收覆盖组件和安装交付，不代表已经连接真实控制器。

## 组件变更

| Before | After |
| --- | --- |
| `telemetry-card.tsx`：通用数值卡片 | 测量身份、来源、精度、单位、量程、质量与时效一起展示。零值和负值有效；无效质量隐藏数字；离线保留标明用途的历史快照。 |
| `data-freshness.tsx`：主要表达距离上报的时间 | 分离质量与时效，支持采样时间、接收时间、预期周期、来源、未知时间以及紧凑和完整两种视图。由调用方提供时钟，组件不假装实时轮询。 |
| `telemetry-chart.tsx`：单序列小图 | 多序列共享时间轴；同单位共轴、异单位分图；目标带、事件、共享游标、键盘操作、精确数据表。空窗口明确提示，显式缺测和超间隔均断线，游标与表格精度一致。 |
| 缺少灯光控制组件 | 新增 `light-control.tsx`：按能力显示开关、亮度、色温、颜色与场景；实际值与草稿分离；群组部分失败保留成员反馈和未生效草稿。 |
| 缺少温控组件 | 新增 `thermostat-control.tsx`：实测温度、生效目标、模式与当前运行状态分离；支持热/冷/自动双目标、死区校验、临时覆盖、离线、失败与外部目标冲突。 |
| `actuator-control.tsx`：开/停/关基础控制 | 实际位置与目标分别显示；增加行程限位、校准、故障与反馈时间。运动状态来自设备；反向前必须停止。可用操作由在线状态、控制权与联锁原因约束。 |
| `setpoint-control.tsx`：数值步进与提交 | 支持量程、步进与无效参数校验；失败保留草稿；外部修改时阻止覆盖，并提供采用设备值或保留草稿后重新确认。 |
| 缺少控制权组件 | 新增 `control-authority.tsx`：区分本地/远程、手动/策略、持有者和状态来源；临时覆盖到期不会被当成控制权已释放；申请与释放由能力和权限控制。 |
| 缺少联锁组件 | 新增 `interlock-status.tsx`：展示上游许可/阻止/未知判定；条件支持满足、未满足、未知、陈旧及展开来源和时间。空列表不能推断允许操作。 |
| `command-status.tsx`：简单 pending/confirmed 反馈 | 完整排队、发送、接收、运行、验证、拒绝、失败、超时未知、取消；请求 ID、事件时间、请求值和设备回读可查。仅在允许阶段提供取消/重新提交，旧请求的操作错误不污染新请求。 |
| `alert-card.tsx`：告警卡片和确认按钮 | 活跃/恢复与已确认/未确认独立组成四态；未知条件单独显示；补齐来源、发生/恢复/确认时间、确认人和搁置元数据。确认不清除条件。 |
| 缺少运行过程组件 | 新增 `irrigation-run.tsx`：任务与区块、阶段与队列、计划/累计水量、流量、设备剩余估计；未知总量不伪造百分比；暂停、恢复、确认停止均等待回执。 |

## 共用状态与导航

| Before | After |
| --- | --- |
| 各组件独立处理提交 | `iot-model.ts` 与 `use-device-command.ts` 共用请求关联、并发保护、AbortSignal、超时及事件顺序约束。`Promise<void>` 只表示 accepted；只有显式 verified 回执才标为验证成功。 |
| 旧状态事件可能覆盖新结果 | 请求 ID 不一致、时间倒退、阶段回退及终态冲突被忽略。超时仍属结果未知；匹配的后续验证事件才可解决该状态。 |
| 四类 Components，设备卡与测量混放 | 六类：感知与测量 2、数据可视化 3、控制与执行 10、事件与告警 3、设备与空间 3、配置与运维 1，共 22 个组件。 |
| 控制模式包含 AI | `control-mode.tsx` 使用 `manual | auto`。AI 建议属于自动化辅助信息，不作为第三种控制权模式。温室 Block 同步更新说明。 |
| 通用预览不能验证各组件状态 | `FirstBatchPreview.tsx` 为 12 个组件提供独立场景、真实可操作的本地状态转换和重置。目录展示针对每类组件的样本，首批组件标明完成批次。 |
| Registry 共 23 项 | 共 30 项：22 个组件、4 个 Blocks、主题、两个工具模块和一个命令 Hook；依赖闭包检查通过，独立消费者通过官方 CLI 安装。 |
| 文档以旧目录和旧回调语义为主 | README、组件接口页和 Docs 更新分类、状态语义、调用契约、主题尺寸规则及安装入口。 |

Blocks 保持 4 个可安装场景和 3 个规划占位。Icons 保持六组 36 个明确占位，不宣称已经完成专用图标画稿。

## Theme 配置及材质

按钮 API 参照 [shadcn Button](https://ui.shadcn.com/docs/components/base/button) 的六种变体、四档文字按钮和四档图标按钮；输入状态参照 [shadcn Input](https://ui.shadcn.com/docs/components/base/input)，语义变量与 [shadcn Theming](https://ui.shadcn.com/docs/theming) 对齐。以下分类编辑器是本项目的配置能力，并非声称 shadcn 提供相同的配置面板。

| Before | After |
| --- | --- |
| “组件高度”只影响部分控件 | `theme-settings.ts` 将共享控件高度解析到按钮、输入框、Select、导航、菜单项和 Tabs；关联 XS/SM/LG 与图标按钮高度，随基础字号保证最小容纳空间。 |
| 按钮只有少量统一配置 | Button 分类 10 项：四档高度、内边距、图文间距、图标尺寸、字号、圆角、边框。八种按钮尺寸均实际消费对应变量。 |
| Input 与 Select 尺寸缺少独立映射 | 输入与选择分类 10 项：Input/Select/SM Select 高度、各自内边距、字号、圆角、边框、Textarea 最小高度和上下内边距。 |
| 导航的硬编码尺寸与其他控件脱节 | 导航与侧栏分类 8 项：行高、内边距、间距、圆角、字号，以及桌面、移动、图标侧栏宽度。站点导航与目录同步消费变量。 |
| 菜单行与浮层几何配置分散 | 菜单与浮层分类 9 项：行高、左右内边距、圆角、字号、容器留白、最小宽度、弹层留白、Dialog 宽度和浮层边框。 |
| Tabs 高度与字号缺少统一尺度 | 新增 Tabs 尺寸分类 3 项：高度、字号、间距；已确认的滑块圆角、容器宽度和内边距控制保留。 |
| Tags/Table/Avatar 使用零散默认值 | 分类 8 项：标签高度、留白、圆角、字号；表格行高、留白、字号；头像尺寸。 |
| Checkbox/Switch/Slider/Progress 不在同一配置体系 | 分类 6 项：复选框尺寸、两档开关滑块、Slider 轨道与滑块尺寸、Progress 高度。 |
| 分类覆盖后不易回到统一尺度 | 每项显示独立覆盖，清除后恢复自动跟随；JSON 保存原始共享设置和显式覆盖，CSS 输出预览使用的完整解析值。旧版 JSON 保持兼容。 |
| Theme 缺少跨组件比较 | `ThemeCoveragePreview.tsx` 同屏比较默认控件、八档按钮、六种变体、无效/禁用输入、文本域、导航、Tabs、标签、表格和滑块。 |
| 部分活动态使用加粗表达选中 | 活动按钮、导航、菜单与 Tabs 的字重和几何保持不变，以已确认材质及颜色表达状态。实测导航和 Tabs 选中前后宽度与字重不变。 |
| 窄屏内容容易挤压控制区 | 灯光输入与 Slider 在窄容器改为上下排列；温控实测/目标在窄屏叠放；趋势游标独占一行，数值统一格式化；触屏操作行保留可点击尺寸。 |
| 新分类可能绕开已有材质 | 所有分类复用 canonical Graphite 样式。凹陷区域无额外边框，浅深色均保留 `inset 0 2px 4px rgb(0 0 0 / 0.07), inset 0 0 0 0.5px rgb(0 0 0 / 0.08)`；继续使用短阴影、普通标题及收敛的滚动条。 |

七组共 54 项组件细节控制，其中新增 37 个专属变量，其余复用已有参数。颜色、字体、基础尺寸、独立圆角、Tabs 材质、反馈与阴影仍在原有分类中。直接编辑导出的 CSS 时，应修改相应的已解析分类变量；共享尺度的自动推导由编辑器与 JSON 设置完成。

## 验收结果

| 范围 | 结果与证据 |
| --- | --- |
| 类型检查与生产构建 | `npm run check` 成功；31 项测试全部通过；[完整日志](../outputs/first-batch-20261104/final-check.log)。 |
| 数据和生命周期边界 | 测试覆盖乱序/旧请求、终态、超时后的匹配验证、零值、异常范围、步进、时间、告警四态、未知灌溉量、趋势缺口与重复采样、主题继承和导入校验。 |
| 真实浏览器交互 | 设定草稿冲突、失败保留、温控死区与成功回读、执行器停后反向、灯光群组部分失败、控制权申请/释放、联锁展开、取消、超时未知、告警确认/恢复、灌溉暂停/停止均通过可见交互核对。 |
| Theme 尺寸 | 默认 Button/Input/Select/Nav/Tab 均 32px；共享 48px 后均 48px，菜单项也 48px；XS/SM/default/LG 为 36/42/48/54px。输入框单独 40px 不影响其他类别，恢复自动回到 48px。 |
| 活动态稳定性 | 导航项选中前后宽度均 52px、字重均 400；Tabs 选中前后宽度均 86px、高度均 32px、字重均 500。 |
| 参数复用 | 在浏览器下载 JSON、改变设置后经文件选择器导回，恢复 48px 实际尺寸。验收结束已恢复 32px 默认共享尺度。 |
| 响应式 | 首批 12 页在 320px 下文档宽度均为 320px；修正后灯光轨道 160px、趋势轨道 200px；Theme 编辑器文档宽度 320px。临时视口覆盖已清除。 |
| 材质与滚动 | 浅深色独立消费者均测得凹陷边框 0px，内描边 shadow spread 0.5px；检查了界面截图和控件布局。 |
| 独立安装 | 新临时 React 项目完成 `npm ci`，官方 shadcn CLI 安装主题和全部 12 项及传递依赖，类型检查与构建通过，真实浏览器渲染与设定值提交通过；[最终消费者构建日志](../outputs/first-batch-20261104/consumer-build.log)。 |
| 浏览器错误 | 最终主站验收时未记录 error/warn。独立测试页面的主题切换测试代码曾有 effect 返回值问题，已修正并重新检查浅深色；不涉及交付组件。 |
| 交付产物 | 更新 production `docs/` 镜像，并恢复本地 registry URL 供开发预览安装；`git diff --check` 通过。未发布远端版本。 |

[浏览器原始记录](../outputs/first-batch-20261104/browser-checks.json) 保留检查过程及修正后的复测结果。发现并修正的问题包括温控自身成功回读误判为外部冲突、取消场景未更新、窄屏滑动条过短，以及空窗口演示和数字显示精度。

生产构建有主入口约 526 kB 的分包提示；当前构建成功，首次加载优化仍可继续。组件属于 UI 和接入契约，设备鉴权、联锁决策、命令可靠投递与持久化由接入系统负责。
