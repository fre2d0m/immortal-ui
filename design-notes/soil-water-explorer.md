# 土壤水分年度分析

`soil-water-explorer` 用于沿同一时间轴核查多深度水分、气象区间量和现场事件。安装入口为 `r/soil-water-explorer.json`，演示入口为 `#/blocks/soil-water-explorer`。全年、重叠事件、跨年核对与空数据场景均调用同一可安装组件；合成记录独立放在 `src/lib/soil-water-demo.ts`，不进入安装包。

## 阅读顺序与视觉编码

| 阅读任务 | 呈现 |
| --- | --- |
| 看全年垂向差异、季节变化和跨层缺口 | 深度 × 时间热图。行是离散探针，不代表连续土层厚度；按深度排序，时间按真实区间宽度定位。色阶由全量记录确定，缩放不变色。 |
| 比较具体深度 | 同尺度曲线、稳定的颜色与线型；默认选择少量深度，可选择全部 20 层。读数行可点选突出对应曲线，六层以内在曲线末端直接标注深度。原始记录不平滑；缺测、无效或超过 1.5 个采样周期的间隔断线。 |
| 核查短时峰值与覆盖 | 全年视图为 24 h 分箱均值，细线保留 min–max；不完整分箱不连成正常趋势。底部点线标记覆盖或质量问题，无效值另用斜纹。两周以内切换为采样间隔分箱。 |
| 比较水量与参数 | 降雨与 ET₀ 的原区间水量同轴，零为基线；Kc 单独绘制无量纲区间值。全年尺度固定。气象记录不随缩放拆分或按比例分摊。 |
| 看持续与瞬时事件 | 区间带与菱形；同类重叠事件分行，未知结束时间显示持续中。定位事件后，对应区间贯穿各图高亮。 |
| 核查数值 | 可固定的联动读数、键盘游标、当前范围原始记录表和导出。宽屏当前读数固定在右侧，窄屏从游标时间旁打开读数浮层；宽表局部滚动。 |

工作区按可用高度分配空间。水分比较为主区，热图提供紧凑的深度背景；降雨/ET₀、Kc 和事件保持独立尺度并压成关联轨道；所有轨道只显示一条底部时间尺，游标和事件选区贯穿各层。完整深度选择与区间质量信息按需打开；20 层全选时只有读数列表局部滚动，不增加画布高度。大字号和极矮视口保留最小可读尺寸，允许滚动，不以裁切维持同屏。

默认水分纵轴使用全年所有深度的观测范围（包含边界留量），可切换参考范围（越界观测仍扩展显示）。按钮和刻度明确显示当前范围；同一对象的时间缩放、深度选择和事件定位都不重新计算纵轴，范围始终来自同一组全年记录。柱形气象量仍从零开始。

选中事件使用一条贯穿各轨道的浅色时间带和实际边界；未知结束时间不画虚构的结束边界。游标圆点使用对应观测的实际采样时间；分箱均值落在分箱中心。读数中只省略与公共时间完全相同的重复时间，不同时间继续单独显示。

导航缩略曲线使用最浅层的 24 h 均值，仅用于选择时间窗口。曲线、热图、读数和表格不从截图或硬编码图形生成。

## 数据契约

类型与数据处理：`registry/immortal/blocks/soil-water-model.ts`。

- 所有时间均为 epoch milliseconds，窗口和区间使用 `[from,to)`，`timeZone` 负责显示时区。采样间隔、单位、精度、参考范围、来源由调用方提供。
- `depths` 包含稳定标识、实际安装深度和原始 `TelemetryPoint`。沿用公共遥测契约：排序，重复时间戳保留最后收到的记录；无效时间排除并报告。空值、无效值和未报告时隙分别计数。
- 分箱保留有效样本数、接收数、已覆盖时隙、计划时隙、极值、原始样本时间及质量。一个时隙的多次观测不会假装覆盖多个时隙；超量程观测扩展显示范围。
- `rainfall` / `et0` 是具有明确起止时间的区间量，叠加时单位与累计长度须相同。重叠区间或声明长度不一致会显示定义错误，组件不会自行重算业务口径。未提供的系列保持空白。
- `kc` 是无量纲参数，单位为 `1`。不自动计算 ETc、灌溉需求、根区储水、胁迫或故障因果；这些结果需要独立的业务定义与输入。区分 Kc 与参考蒸散的依据见 [FAO-56 第 5 章](https://www.fao.org/4/x0490e/x0490e0a.htm)。
- 事件使用 `instant` / `interval` 明确区分瞬时与持续；持续事件没有 `to` 表示结束时间尚未提供。`depthIds` 未提供不解释为影响所有深度。事件原边界在定位、表格和导出中保留。
- `onExport` 收到当前窗口、所选深度的原始记录、与窗口相交的完整气象区间及事件。演示下载为 JSON，NaN / Infinity 显式序列化为字符串，避免与空值混淆。
- 更新同一对象的记录时保留当前窗口与选择，窗口收缩时约束到实际范围；切换 `data.id` 时恢复新对象的初始视图。

## 渲染与接入边界

使用 ECharts 的 Canvas、时间轴、多网格、区间图元和 dataZoom。按需导入并延迟加载，基础卡片不依赖 ECharts。选择依据为密集矩阵与多轴工作区，参考 [ECharts 渲染器说明](https://echarts.apache.org/handbook/en/best-practices/canvas-vs-svg/) 和 [按需导入](https://echarts.apache.org/handbook/en/basics/import/)。Canvas 外提供完整的名称、联动读数、控件及原始表格。

结构样式随 Block 安装，材质与控件仍遵循 Graphite。分析配色分开表达有序水分、深度类别、气象量和事件；深浅主题分别提供具有足够对比度的颜色。深度色可通过 `--soil-depth-1` 至 `--soil-depth-5` 覆盖，其余语义色见 Block CSS。网站、独立安装及 Theme 页面使用同一组件；目录缩略图复用相同数据处理与色阶函数。

当前组件接收内存中的年度数据，不包含数据库查询、网络分页、实时订阅、天气模型或真实设备接入。渲染分箱是明确披露的展示聚合，不代表业务数据被替换；表格和导出保留原记录。数据规模验证见 `outputs/soil-water-20261113/verification.md`，同屏布局与交互验证见 `outputs/soil-water-compact-20261113/verification.md`，不外推为任意数据量、设备或浏览器的保证。

视觉重构与独立安装复审见 `outputs/soil-water-design-20261113/verification.md`。
