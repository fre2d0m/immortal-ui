# 工作流连线入口 · 2026-11-13

本次把“添加下一步”“插入步骤”“新增并行分支”分开，消除一条连接两端重复加号。覆盖可安装 Block、相同组件的展示页与独立安装宿主，延续 Graphite 的图标、材质与反馈。

## 统一规则

| 对象 | 原表现 | 当前规则 |
| --- | --- | --- |
| 输入端 | 也显示短线与加号，增加阅读负担 | 保留连接手柄与拖线能力，不显示快捷加号 |
| 未连接输出 | 短线与加号 | 保留；点击添加下一步或连接兼容的已有节点 |
| 已连接输出 | 原加号仍显示，与另一端入口重复 | 隐藏端点加号，每条连线只在路径长度中点显示一个插入入口 |
| 并行追加 | 与沿线插入混在同一端点上 | 已连接的并行节点在标题旁提供分支图标；新增一路保留已有边，在线上插入只替换指定边 |
| 分支文字 | 占据连线原标签位置，与新增入口竞争 | “命中 / 未命中 / 失败”来自原 `port`，独立显示；中点切线为横向时在按钮上方，竖向时在右侧 |

加号可见圆直径 24px，画布坐标下命中区域 40×40px，随画布缩放。分支文字避开这一区域，普通输出不重复标注。标签不充当按钮，不依赖悬停；只读和运行中隐藏编辑入口、保留文字。悬停、按压、焦点、减少动效沿用原规范。

插入复用现有连接规划：保留来源出口，兼容性校验通过后一次替换原边；并行兄弟分支不变。输入端拖线、连接到已有节点、拖到空白选择节点以及选中线的重接手柄继续可用。新增入口支持右键、Shift+F10 与 Escape 焦点返回；无效数据类型仍不可选。

## 实现依据

采用 React Flow 的 [自定义边标签层](https://reactflow.dev/learn/customization/edge-labels) 与 [Smooth Step 路径](https://reactflow.dev/api-reference/utils/get-smooth-step-path)。按实际路径长度定位插入入口，避免用边界框中心造成按钮偏离折线；项目负责连接含义、焦点与视觉规范。
