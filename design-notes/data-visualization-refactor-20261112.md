## 数据与尺度契约

- `normalizeTelemetry` 是图形、查询表格和导出共同使用的标准化入口。沿用包含两端的时间窗口、按时间排序、同时间戳最后接收记录生效。不会因最后记录缺测或无效而回退到更早的值。
- 时间必须是有效的 epoch 毫秒。无效时间不能进入时间轴；趋势组件和历史工作区都会报告被排除的数量。未传入记录、无此时刻采样、缺测、非有限值或来源判为 bad 的记录分别表达。
- `TelemetryPoint` 可附 `quality` 与 `qualityReason`。质量缺失显示“未提供质量”，不会默认有效。数值有效但估算/存疑的点保留，分别以方形/菱形及文字标注；bad 或非有限值断线。
- `maxGapMs` 是调用方定义的最长连线间隔。未提供时仅断开显式缺测/无效记录，并说明未提供长间隔规则；展示层不推测容差。温室与首页的演示场景显式提供该值。
- `TrendHistory` 增加 `window` 与 `domain: { min, max }`；`TrendSeries` 可传 `domain`、`styleIndex`、`precision` 和 `kind`。并列概览需要比较幅度时传入相同 domain。`styleIndex` 使用 0–4 的整数指定稳定色与线型；未提供时由序列 id 稳定映射。
- domain 表示显示参考范围，不是报警阈值，也不是裁剪边界。超出范围的实际读数会扩展显示并说明。没有 domain 时标明自动尺度；不把自动放大的局部变化伪装成绝对量。
- 同单位序列的尺度涵盖所有已查询序列，包括通过图例隐藏的序列。不同单位分图。参考目标带有可见边界和文字，不依赖浅色填充表达。
- 实时图保存所选时间戳；插入较早记录不改变选中对象。选中采样不再存在时明确提示并提供“返回最新采样”。自动尺度会随窗口更新，界面明确交代。
- 读数与表格遵循相同精度。导出保留原始值及 `state / quality / qualityReason`，查询条件采用已经应用的查询，不跟随尚未提交的表单草稿。日期保留年份，非整秒采样保留毫秒。

## 演示记录

演示值位于 `src/lib/data-card-demo-data.ts`、`chart-demo-data.ts`、`block-demo-data.ts` 与 `demo-data.ts`，不作为安装依赖。

- 空气温度默认最后两个有效观测为 24.2、24.6 °C，所以比较值为 +0.4 °C；趋势最后一点与主值相同。
- 均温演示每次计算使用 15 分钟、3 通道、30 秒间隔的 90 条输入，其中 3 条缺测。有效输入合计约 2140.2，除以 87 得到 24.6 °C。显示的样本数、历史结果、最新均值与上一窗口比较都从这些输入生成。这是可重复的合成演示，不是实际温室计算成果。
- 历史查询提供可手算案例：跨年窗口中的第 0、1、3、10、20 分钟分别为 0、10、缺测、−10、20。原始输入乱序且末时刻存在旧值 999，最后收到的 20 覆盖旧值。第二序列为 5、15、5，只有共同采样时刻才能逐点比较。
- 可切换单点、常量、空记录、缺测/无效、极端值、不同单位等场景。卡片另有零、负值、越界、跨年及不规则采样场景。

## 实现选择与规范依据

数据标准化、尺度和格式化继续复用本项目能力；小型概览保留轻量 SVG。2026-11-13 起历史分析图的布局、坐标与曲线由 Recharts 承担，Radix 滑块、常驻读数和数据表提供精确读取路径。当前交互限于图例显隐、实际样本选择与数据表，没有新增缩放、平移或降采样。

初次重构评估了 [uPlot 的官方能力说明](https://github.com/leeoniya/uPlot)，当时保留自绘 SVG；后续视觉复查确认历史分析图的自绘坐标和尺寸不够成熟，已替换为 Recharts。大量点位、高频刷新和降采样仍须另行定义规模、选择实现并测量，不能据本轮结果宣称支持。

依据 [ONS 坐标轴规范](https://service-manual.ons.gov.uk/data-visualisation/guidance/axes-and-gridlines)、[Analysis Function 图表指南](https://analysisfunction.civilservice.gov.uk/policy-store/data-visualisation-charts/)、[WAI 复杂图像指南](https://www.w3.org/WAI/tutorials/images/complex/) 与 [WCAG 1.4.13](https://www.w3.org/WAI/WCAG22/Understanding/content-on-hover-or-focus.html)，保留必要尺度、缺口、等效数据表及可持续读取的信息。宽表采用局部滚动与语义表头；必要图形有强制颜色模式下的系统色后备。

验收记录与局限见 `outputs/chart-refactor-20261112/verification.md`。安装契约以类型与实际源文件为准。
