# 基础样式的一致性规则

Graphite 的基础材质与交互共用以下规则；布局由组件的业务职责决定。样式源为 `registry/immortal/styles/graphite.css`。网站、可安装组件、主题及 Theme Studio 导出使用相同来源。

## 交互状态按控件职责区分

共用颜色、圆角和材质，不等于所有控件共用悬停/按下/选中模板。悬停表示“可以操作”，选中表达持续状态；键盘焦点表示当前操作位置，不能借用选中材质。

| 控件 | 持续状态 | 悬停与按下 |
| --- | --- | --- |
| 操作按钮 | 执行中的禁用/进度，或菜单是否展开 | 保留按钮材质的明暗与按压反馈；不是内容的当前选择。 |
| Tabs | 仅一个 `aria-selected=true`；胶囊用一个凸起滑块，线形用一条下划线 | 未选中项悬停只轻调文字，不增加填充、边框或投影。按下可有平面浅底；选中滑块移动期间，触发项自身仍透明，不能同时画两块选中表面。 |
| 导航、筛选、单选分段 | 分别由当前页、筛选值、radio 的 checked 状态表达 | 未选中悬停/按下仅平面浅底，不添加凸起投影；当前项保留选中材质。分段控件仍使用单选键盘行为。 |
| 菜单与选择列表 | 勾号、单选标记或展开箭头 | 悬停和键盘高亮保持平面；不能用高亮冒充已勾选。 |
| Checkbox / Switch | 勾选标记、开关位置 | 悬停不能产生勾号、移动滑块或修改状态。 |
| Slider | 滑块位置与数值 | 悬停可强调操作点，只有输入操作才改变值。 |
| 输入框 / 多行输入 | 用户输入、只读、错误 | 悬停轻调边缘，键盘焦点有明确轮廓；不伪造选中或已提交。 |
| 折叠详情 | 箭头方向与实际展开内容 | 悬停不能显示为已展开。 |
| 标签、进度、静态说明 | 业务信息 | 无操作语义时不提供按钮式悬停和按压反馈。 |

受限高度的浮层中，标题、搜索与 Tab 栏保持自然高度，仅结果区域收缩并滚动。Tab 与其内容使用同一 Tabs 容器和对应的 TabsContent，禁止让零最小高度的独立栏被挤扁后覆盖下一块内容。检查必须组合“已有选中 + 悬停其他项 + 按住 + 切换过渡”，并覆盖长列表、无搜索结果、深浅主题、20px 字号和窄/矮视口；只检查静止截图或视口是否溢出不够。

## 数据处理工作流工作区

`data-workflow` 是持续编排、测试和排错的编辑工作区，不使用内部 Panel / PanelHeader。共用 Graphite 的按钮、输入框、菜单、Tabs、字体、材质与状态语义。左上角沿用 40px 圆形材质底座及 16px 图标，只作为静态身份标识；工作区布局不继承信息面板的 24px 四边内边距和展示型头部。

- 画布是持续可见的主工作面。空画布以虚线节点选择触发器，已有节点从未连接输出加号就近选下一步，已有连线从中间的加号插入步骤；选中节点才打开配置，流程设置从菜单进入。运行结果在画布下方按需展开，节点导航与执行数据就地相邻；定位画布和查看配置是明确的独立动作。
- 头部以名称、发布状态图标与文字、节点图标与数量、校验图标与数量组织身份信息；保存、测试及次级操作另成一组。状态值动态推导，不拼接成一句副标题；画布内工具栏仅处理撤销、重做和视图控制。取消画布、节点、连接、运行记录四个并列一级切换。
- 缩放工具栏显示实际视口百分比，数字等宽、与图标居中对齐，缩放过程中同步更新。连线加号采用 12px 可见圆、7px 图标、20px 状态高亮与 40px 透明点击区域；悬停、按下、展开及键盘焦点不能重新填充整个点击区域，键盘轮廓围绕 20px 小圆。连接手柄保持 9px，实心与空心以细微渐变和内阴影增加质感，不能靠放大端点或添加光晕制造层次。强制配色保留两类形状。
- 操作控件直接使用共享 Button，相关单行组合使用 `control-row`；不在工作区内统一硬写 40px 最小高度或覆盖共享按钮内边距。默认 34px 与触控 40px 由主题统一计算。
- 头部、画布编辑及缩放工具栏使用同尺寸图标按钮。只有未连接输出带短引线与圆形加号，输入和已连接输出不重复显示；每条连线中间只有一个插入加号。两类加号悬停轻微放大；并行追加分支使用节点标题旁的独立分支图标，避免与插入含义混淆。“命中 / 未命中 / 失败”在连线加号旁独立显示，避开点击区，不依赖悬停。工作区展开与画布适配使用不同图标。动作名称通过无障碍标签与悬停、聚焦提示保留；触屏长按可读提示且不触发动作。更多菜单点击后提供文字操作。名称和结果详情保留文字；三个状态项统一采用“图标 + 可见状态值”：例如 Draft、11 nodes、0 issues，数量按单复数变化。图标统一为 14px、1.75px 线宽，项内间距 6px、项间 16px，文字使用次级信息色；已发布与通过用绿色图标，未发布更改与单项问题用警示图标，多项问题用红色，草稿保持中性。三项均为只读信息，悬停、键盘聚焦、触屏长按使用同一提示；不响应点击，不出现按钮底色或按压缩放，不打开问题抽屉。触控目标至少 40px，换行以完整状态项为单位。
- 运行结果中的输入、输出和执行信息，节点选择器中的新增与连接已有采用现有共享 Tabs。配置侧栏专注参数，执行数据入口打开同一个结果区。策略、技术定义与运行标识默认收起；完整信息保留在可达的配置与结果视图。
- 右键菜单按画布、节点、连线提供当前对象的动作，复用共享菜单的平面高亮和焦点行为。它是快捷入口，触控与常规操作仍可通过端点、配置栏和工具栏完成；切换弹层时不能让旧弹层夺回焦点或关闭新弹层。
- 配置栏在宽屏占独立空间，窄屏排在画布下方；工具栏相对画布定位。连线选中态和悬停态分级，选中后才显示圆形重接手柄，避免与端点加号抢占命中区域。
- 节点使用统一的类型/名称区、关键配置摘要区和独立运行结果行。摘要只展示 1–3 个关键字段或一条结构化表达式，由适配器按参数 key 从当前配置生成；字段和值分列，不取第一项参数、不用分隔点拼接配置、不用描述冒充配置。节点等宽，统一内边距、字号、对齐与区域间距；高度随实际标题行数、摘要条目和已提供的运行记录增长，不为未使用的标题/摘要行留空。多个端点同侧时按实际端点数保留互不重叠的操作区域。长值省略后仍能在配置中完整核查。具体接入契约见工作流说明。
- 底部折叠条只展示运行结果状态与实际总耗时，不混放连接数量和并发配置。展开后以节点导航和数据详情组织；导航每行仅放状态图标、节点名称和右对齐耗时，使用平面底色表示选中，去除左侧装饰线与阴影；长名称视觉省略，提示和选中后的详情保留全文；失败优先、其次运行中、最后完成的成功节点，用户主动选择后保持所选节点。节点状态、耗时、尝试次数及异常来自回执；缺少回执不能推断为跳过。历史、重放与单步执行不以空入口占位。
- 工作流内置文案与演示模板使用英文；宿主提供的业务内容按原值展示。旧版示例草稿仅迁移已知内置名称与标签，不改写自定义业务数据。
- 保存允许不完整草稿；执行前检查必要配置。执行状态、数据与耗时来自实际回执；不把本地模拟测试表达为真实业务投递。

接口和范围见 [数据处理工作流](data-workflow.md)，工作区验收放在 `outputs/data-workflow-refinement-20261112/`，图标入口与提示验收放在 `outputs/data-workflow-icons-20261113/`，节点摘要与视觉规范验收放在 `outputs/data-workflow-node-summary-20261113/`，端点编排验收放在 `outputs/data-workflow-endpoints-20261113/`，连线入口收敛验收见 [连线入口规范](data-workflow-edge-actions-20261113.md)。

## 土壤水分分析工作区

`soil-water-explorer` 是沿共享时间轴持续核查的分析工作区。共用 Graphite 材质、按钮、线形 Tabs 与字体；使用专用的连续色阶、深度分类色、气象色和事件语义色，避免不同含义共用同一分类调色板。只使用一层外壳，比较曲线是主区，热图提供紧凑的深度背景，气象、Kc 和事件是紧凑关联轨道。工作区高度随可用视口分配，五个图层共享底部时间尺、游标和窗口导航，不各自重复标题留白和时间轴。

- 桌面标题、视图切换与次级操作同行；时间范围、深度选择与窗口操作组成查询栏。轨道名称和单位位于左侧，分类色与线型和当前读数一起出现在右侧；少量曲线直接标注深度，读数行可点选突出相应曲线。轴和必要说明保持可读字号，不能靠缩小文字来压缩布局。
- 20 层完整选择与剖面读数放入浮层；右侧只常驻当前所选深度、气象值与关联事件。增加所选深度不增加工作区高度，长读数列表局部滚动。
- 窄屏保持全部关联轨道，详细读数由游标时间旁的浮层打开，不追加到画布下方。控件沿用共享尺寸与触控最小值；大字号或极矮窗口允许局部滚动，不能裁掉数据含义。
- 展开采用原生 dialog，保留当前数据范围与深度选择；关闭后焦点回到入口。数据契约与编码见 [土壤水分年度分析](soil-water-explorer.md)。

## 设备档案 Device Profile

`device-profile` 是独立的页面级设备档案，依据用户提供的完整设备参考图设计。它拥有自己的布局，不使用内部 Panel / PanelHeader，不继承面板的圆形图标底座、固定头部高度、四边内边距或凹槽状态带。共用字体、颜色、按钮、菜单与状态语义。

| 区域 | 内容与布局 |
| --- | --- |
| 实物图 | 宽屏放左侧，占据整组档案的视觉高度，使用 contain 保留比例；无图时收回图片列，不用通用图标代替实物。 |
| 名称与分类 | 设备名称是首要标题，连接状态紧邻；分类标签在其下方平面排列，标签没有按钮材质。 |
| 出厂身份与用途 | 序列号及复制、型号同行；其下为用途描述。共享文字起点，允许长名称与标识换行。 |
| 右上操作 | 配置打开设备配置，服务菜单列出宿主提供的设备能力；两类操作高度一致，禁用原因在菜单中显示。没有回调时不制造无效入口。 |
| 运行摘要 | 最近活动、电源、信号与协议、位置平面并列，不拆成数字卡片或凹槽。时间含义明确标注。 |
| 补充档案 | 平台标识及独立复制、产品、版本、安装日期、部署、工作和准入状态降低视觉权重；只显示已提供的扩展信息。 |

窄屏保留图片与名称横向组合，操作和正文移到完整宽度，字段自然换行。组件用于设备详情页顶部；`device-card` 继续作为概览卡片。完整档案不套用下方的面板结构规范。

## 数据卡片：按数据含义组织

本库的 Metric / Indicator 边界沿用当前工程的 Telemetry（设备观测事实）/ Indicators（平台衍生结果），不是把两个英文词当作全行业唯一的标准定义。`Metric Card` 和 `Indicator Card` 是公开的业务组件；质量、时效、迷你趋势与范围仪表属于其内部能力。

| 内容 | Metric Card | Indicator Card |
| --- | --- | --- |
| 本质 | 设备实际报告的一项观测 | 规则、聚合或模型生成的一个结果 |
| 定义与上下文 | 标识、名称、作用对象、数据类型、单位、显示精度、可选分辨率、范围与预期采样间隔 | 标识、名称、作用对象、结果类型、单位或分类映射、结构化结果列定义 |
| 来源 | 设备与测量通道 | 计算方法、可选版本和输入依据 |
| 实际数据 | value、采样时间、接收时间、来源报告的质量与原因 | value、计算时间、输入统计窗口、结果质量与原因 |
| 呈现 | 数值可用数字、趋势或范围；枚举和布尔按定义呈现；文本保留原意 | 数值可用同样的可视化；等级按状态定义呈现；结构化结果用表格 |

来源决定必须交代的信息，值类型与查看目的决定可视化。不能规定“Metric 一律折线、Indicator 一律仪表”；更换图形不改变数据定义、来源或主数值。范围图不再带第二个面板头和第二个主数值，趋势不桥接缺测区间。

两类卡片共享阅读顺序：名称与作用对象 → 主值或主要结果 → 比较基准和解释 → 可选可视化 → 时间与质量 → 关联信息。详细来源与定义在卡片内展开。比较须明确绝对差、相对变化或百分点，变化方向与好坏评价分别提供。零值、false、空结果表、无记录、无效记录和读取失败分别表达；计算时间不冒充采样时间，也不证明输入数据新鲜。

当前接口是展示层数据契约，宿主负责从产品定义和实际记录适配。未执行真实测量或计算；模型版本、输入依据和结果得分仅在宿主提供时显示。现有实现覆盖数值、枚举/布尔、文本及衍生结果表，未宣称支持当前工程所有图像、音频、空间与多位格数据形态。

目录合并原“感知与测量”和“数据可视化”为“数据与指标”。旧的 `telemetry-card`、`data-freshness`、`telemetry-chart`、`range-gauge`、`daily-histogram` 安装地址保留兼容并标记为内部项，不再作为业务案例展示或计数。原页面转向新卡片或已有的历史查询工作区；历史筛选、游标、表格和导出仍由 `telemetry-explorer` Block 承担。

实现入口为 `metric-card.tsx` / `indicator-card.tsx`，共用的 `internal/data-card.tsx` 只组织内部呈现；`internal/data-card-model.ts` 保留数据形态、比较和格式化规则。设备详情的读数区域复用 Metric Card，独立 Device Profile 继续负责设备身份。

### 数据卡片视觉验收规则

| 检查部位 | 规则 |
| --- | --- |
| 标题与操作 | 沿用 40px 圆形图标、12px 图文间距及默认 24px 内边距。头部到正文只保留一份 24px 间距；标题和副标题可向下换行。历史入口只有一个图标按钮，窄卡片仍放在右上角，与身份图标垂直中心对齐。 |
| 数据主次 | 主要结果最高权重，单位次之；比较值与基准构成完整语义组，宽度不足时整体移到下一行。长数值缩放后保留完整数位，不从数字中间换行；极长值保留局部滚动。长说明与标识可换行，不溢出卡片。空文本明确显示“空文本”。 |
| 趋势 | 显示实际起止时刻、单位、极值及历史口径；缺测保留断线并标注“含缺测”。迷你趋势用于概览，逐点查询继续由历史工作区承担。 |
| 范围 | 卡片内使用位置轨道，主数值不重复。标出量程两端、目标区间和当前位置；处于最小值时仍显示位置标记。目标外与量程外用文字区分，颜色只作辅助。 |
| 结构化结果 | 文字左对齐、数值右对齐并使用等宽数字；columns.precision 可规定小数位。保留表头与单位，窄宽度优先局部滚动，不把数字或类别拆成碎片；超宽时出现滚动提示，滚动区支持键盘。 |
| 时间与质量 | 年、月、日和时区完整；日期与时钟分别保持完整，可在二者之间换行。同日窗口只写一次日期，跨日窗口保留两端日期。计算时间、输入窗口与质量各自独立。质量色与 Metric Card 一致，正向小字使用满足对比度的 success-text。 |
| 详情 | 来源、定义、算法与输入依据默认收起。整行触发区至少 40px 高；悬停、按下只轻调文字明暗，展开通过箭头及实际内容表达；键盘焦点清晰。 |
| 材质 | 卡片外壳与图标底座凸起；主值、比较、图表、表格、元信息和详情处于平面。Indicator 用计算符号识别衍生结果，不以 AI 图标暗示所有结果都由模型生成。 |

走查覆盖深浅主题、505px 与 288px 卡片宽度、320px 视口、20px 字号、长内容、不同数据形态与异常状态。默认主题以普通文字 4.5:1、大字及必要图形 3:1 为下限；触控入口采用项目的 40px 规则。任意用户自定义颜色需另行检查。依据 [WCAG 2.2 文字对比度](https://www.w3.org/WAI/WCAG22/Understanding/contrast-minimum.html)、[非文字对比度](https://www.w3.org/WAI/WCAG22/Understanding/non-text-contrast.html)、[重排](https://www.w3.org/WAI/WCAG22/Understanding/reflow.html)与[目标尺寸](https://www.w3.org/WAI/WCAG22/Understanding/target-size-minimum.html)的相关条款，不将局部走查等同于完整无障碍认证。

## 业务面板

设计与交付以完整的业务对象和任务为单位。头部、图标底座和内容容器是内部结构，不作为独立业务组件展示、安装或计入案例。共用材质和间距不意味着各面板放置同一种信息。

| 面板 | 支持的判断或操作 | 标题与上下文 | 右侧信息 | 主体与反馈 |
| --- | --- | --- | --- | --- |
| 设备概览卡片 `device-card` | 在卡片中核对设备身份与运行情况 | 设备名称与产品；身份信息在内容区 | 连接状态，以及由宿主提供的操作入口 | 保留概览卡片的布局；设备详情顶部使用独立的 Device Profile。未知电量不推断为外接电源，电压不换算成百分比，缺失信号不单独推断离线。 |
| 灯光控制 `light-control` | 设备当前如何运行、要调整什么 | 灯组名称；设备回读或离线最后回读 | 实际开关状态 | 开关、亮度、色温等依能力显示；设备回读与待提交值分开；提交后显示接收、执行、验证或失败结果。 |
| 温控 `thermostat-control` | 实测温度与目标是否一致 | 区域或设备；运行上下文 | 当前运行状态 | 实测值、目标和模式各有位置；目标修改后显示提交及回读结果，不用运行模式推断正在制热或制冷。 |
| 历史查询 `telemetry-explorer` | 什么时候发生变化、证据是什么 | 指标或数据集；时间范围与采样口径 | 结果摘要或数据状态 | 时间筛选、趋势、游标及原始样本同属查询任务；图例保持平面，缺口不插值冒充观测。 |
| 告警处置 `alert-card` / `alert-console` | 发生了什么、是否还在发生、是否已处理 | 告警事项；来源设备与时间 | 等级及处置状态 | 触发依据与影响在前，确认等动作及反馈在后；已确认与已恢复分别表达。 |

Theme 页面使用 Metric Card、Indicator Card 和独立 Device Profile 检查主题。组件详情与 Blocks 负责展示正常、缺测、离线和操作反馈等完整场景。

## 面板结构

采用用户指定的圆形图标底座材质。一个独立面板承担一个对象或任务，头部使用横向结构：图标在左，标题与副标题组成文字组，面板状态与次要入口在右。主要内容、补充信息与操作反馈依次位于头部下方。

| 区域 | 内容职责 | 统一呈现 |
| --- | --- | --- |
| 左上图标 | 识别设备、测量、趋势或任务类型 | 40 × 40px 圆形底座，16px 图标居中；复用 `surface-control` 的明暗渐变、细边、上沿高光与短投影。每个独立面板只出现一次。标识没有交互、悬停或按下反馈。 |
| 标题 | 回答“这是什么”：对象名、指标名或任务名 | 放在图标右侧，与副标题左对齐。16px 起、统一字重、允许换行。运行状态和主要读数各自在状态位和内容区呈现。 |
| 副标题 | 为辨认对象补足必要上下文 | 位置、来源、设备标识或时间范围，优先提供最有辨识作用的信息。弱化文字、14px 起，与标题间隔 4px。信息不足时直接省略，长文本自然换行。 |
| 右上信息 | 属于整个面板的状态、摘要或次要入口 | 一个简短状态，可配查看、刷新或更多入口。设备概览可提供配置和服务两个有明确分工的操作组。头部内容宽度不超过 360px 时，该区域移到文字组下方并与标题左对齐，图标与文字仍横向成组。整体采样时间可放此处，各指标自己的时效跟随各自读数。筛选器、主数值和执行设备操作放到内容区。 |
| 主要内容 | 支持当前任务的读数、图表、列表或编辑表单 | 与头部整体共用面板左右边距。主要读数使用等宽数字、紧邻单位。数据或编辑区可用单层凹槽，正文与表格可直接放在面板上。 |
| 补充与操作 | 质量、时间、来源、约束，以及操作结果 | 按主要内容、解释信息、动作、反馈的顺序排列。执行操作靠近作用对象；提交和回执放在内容下方，保留请求值与设备回读的区别。 |

Graphite 预设使用 24px 面板四边内边距、12px 图标与文字的水平间距、24px 头部到内容的间距、4px 标题到副标题间距。图标和标题都从头部顶边起排，不随副标题有无进行垂直居中；文字区至少 48px 高，较长标题或副标题只向下扩展。默认 1px 边框下，图标和标题相对面板外边缘的上偏移均为 25px，图标左偏移也为 25px。主要读数和编辑凹槽使用 16px 内边距。圆形图标是固定的身份形状，半径为自身尺寸的 50%；面板和凹槽圆角继续跟随 Theme 配置。用户调整字体、卡片边距、控制材质和阴影后，共用结构一起变化。

### 排列方式的适用范围

图标作为对象类型标识时，与名称横向成组。结果反馈、空状态等以单一消息为主体的区域可以另行采用纵向视觉构图，但这不能作为设备与数据面板默认头部的依据。参考 [Ant Design Result](https://ant.design/components/result/) 与 [GitHub Primer Blankslate](https://primer.style/product/components/blankslate/) 的具体使用场景。

### 凸起、平面与凹陷

- 独立面板外壳使用 `shadow-surface`，图标底座使用 `shadow-control`。两者复用同一光源方向，图标投影保持短而清晰。
- 正文、小标题、分组、图例、状态和元信息处于平面。状态通过文字和可选语义色辨认；图例显示状态使用平面底色，隐藏序列加删除线，键盘焦点有轮廓。
- 主要数据区和编辑区可使用 `surface-inset`。凹槽内部的分组继续使用留白，嵌套凹槽不再重复背景、边界与内阴影。
- 按钮、Tabs 和菜单继续遵循各自已有交互规则。图标底座虽复用控制材质，仍是静态对象标识；按钮有明确的操作语义和状态反馈。
- 列表行、表单字段、图表内的标题、反馈记录和面板内的分区使用平面子标题，避免重复堆叠圆形底座。复用的趋势组件置于面板内部时使用 `embedded`，保留可访问名称、图例和交互。

### 内容区约束

- 测量先给值和单位，再给质量、时效、量程与来源。缺测显示占位与原因，零值仍显示为零，离线快照显式标明。
- 图表先给对象与时间范围，图例与数据同处内容区；坐标、单位、时间窗与采样断点保留。图例视觉权重低于执行操作。
- 列表与查询先给筛选条件，再给结果、数量及分页。筛选控件不得挤占面板状态位。
- 控制先交代设备回读或实际状态，再提供可操作项，最后显示提交状态和回读结果。危险动作继续保留原有确认流程。
- 空数据和错误保留原面板结构，说明发生问题的具体区域。主体内容在窄屏换行或堆叠，状态不遮挡标题，标题不被强制截断。

### 实现入口与覆盖

需要面板形态的组件由 `registry/immortal/components/internal/panel.tsx` 统一外壳、四边内边距、头部与内容区。`panel-header.tsx` 只负责这个外壳内部的身份区排布。两者随所属业务组件一起安装，不单独展示或安装。面板组件无需再包一层 Card；图表以 embedded 模式放入已有面板，字段、状态和指令反馈组件由所在面板组织。`device-profile.tsx` 独立实现设备档案布局，安装时不携带这两个面板文件。

共用材质与布局接入设备、数据卡片、灯光、温控、执行器、灌溉、控制权、联锁、告警和建议，以及业务 Blocks 中需要面板形态的区域。趋势、范围、时效和内部子区使用相应的内部呈现，不再作为独立的业务面板陈列。

## 使用约定

- 并列的单行控件使用同一高度档，按外框而非文字或阴影对齐。Graphite 默认高度为 34px；触屏下按钮、图标按钮、输入框、选择器、导航、筛选和 Tab 至少 40px，图标按钮同时保持正方形。触控下限在各控件自身的尺寸规则中计算，避免被变体或页面选择器覆盖。
- 独立单图标操作按钮在 XS / SM / Default / LG 各档均使用圆形轮廓（等宽高、50% 圆角），不继承文字按钮的基础圆角或胶囊开关。Primary、Outline / Secondary、Ghost 以材质和颜色区分权重，所有悬停、按下、禁用、焦点与展开状态保持同一圆形轮廓。连体分段按钮组按整组外壳裁定端部圆角，中间分段保持直边。文字按钮、字段、Tab 与状态指标分别沿用自身形态。
- 图标操作先按职责分组，再按数量决定外壳：同一组只有 1–2 个按钮时独立呈现，3 个及以上共用紧凑的胶囊外壳，内部按钮仍保持圆形，沿用缩放栏的形式；不为凑数量合并无关操作。按实际渲染的图标按钮计数，缩放比例等读数与提示不计入，禁用按钮仍计入，隐藏或移除操作后自动重算。外壳紧贴内容，窄屏整组换行，不铺满一行制造空白。工作流头部的保存、测试与次级操作有不同权重，四个入口保持独立，不共用外壳；三个缩放操作成组，撤销/重做两个圆形按钮使用独立材质；连接操作中的两个入口独立。共用外壳不改变每个动作的主次、无障碍名称、焦点或方向键导航。
- 共享高度为文字与默认内边距保留最小空间：14px 字号的紧凑档最低 30px，20px 正文字号的共享档最低 36px。单独修改分类高度的配置继续保留。
- 同一条 flex 操作行可标记 `data-slot="control-row"`，其直接子级文字按钮、输入框、选择器和 TabsList 按这一行最高控件撑齐，保留各自的最小高度。Tabs 的轨道内边距计入外框，滑块跟随实际尺寸；换行后各行独立计算。独立图标按钮保持对应尺寸档位、垂直居中，不能随较高的 Tab 轨道拉成椭圆；与输入框配套的加减按钮则同时调整宽高，与输入框对齐。它是内部组合约定，不新增公开组件。
- 表单标签、说明文字、状态标签、Checkbox、Switch、Slider 和多行输入不强行套用单行外框高度；带标签的字段与操作按钮按输入区域底边对齐。显式尺寸档位示例保留 XS / SM / Default / LG 的差异。
- 主面板通过内部 Panel 使用统一的 `surface-raised` 材质；内嵌数据区域使用 `surface-inset`，不再附加 `border` 或 `ring`。需要区分区块时优先依靠间距与底色。
- 页面跳转用真实链接与 `aria-current="page"`；筛选用按钮与 `aria-pressed`；内容切换用 Tabs；单选控制模式保留原生 radio 的键盘行为。
- 普通、悬停、选中和按下保持相同字重、内边距和边框占位。Tabs 的非选中悬停只调文字；导航、筛选、分段的非选中悬停/按下采用平面浅底，不借用选中项的凸起材质。菜单行始终平面。默认按钮原有的渐变翻转与按压反馈保留。
- Tabs 用同一个凸起滑块移动到选中项；线形 Tabs 移动同一条下划线。滑块移动时，当前触发项的悬停和按下也保持透明，避免与移动中的滑块同时形成两处选中底。位移与宽度默认过渡 210ms（跟随动效时长设置），快速改选可从当前位置转向。首次展示、窗口和字体尺寸变化直接对齐，避免无意义的入场或拉伸动画。减少动效时即时定位，强制配色时用选中轮廓保证可辨识。
- 网站和安装包共用 `src/components/ui/tabs.tsx`。设备详情、遥测查询依赖本地 `tabs` 安装项；仅覆盖 CSS 的原生上游 Tabs 保留静态选中后备样式。
- 信息标签不使用按钮的凸起阴影，也不提供无意义的悬停反馈。需要选择、删除或筛选时，使用带交互语义的控件。
- 字段、Checkbox、Switch、Slider、Progress 和对话框沿用原有材质分工。本轮核对它们的层级与共享状态，未重新设计其业务行为。
- 当前已覆盖 14 个原有基础组件、本地 Radix 菜单适配，以及实际页面里的导航与标签。未逐一实现或验收整个上游 shadcn 组件目录。

## 下拉菜单的视觉层级

| 元素或状态 | 材质 | 可见反馈 |
| --- | --- | --- |
| 下拉菜单、子菜单、选择列表的外壳 | 凸起 | 延续 Graphite 的浮层渐变与细边，外投影使用 `shadow-menu`。子菜单展开时形成自己的浮层。 |
| 普通行、分组标题、分隔线、禁用项 | 平面 | 普通行直接显示文字，标题用弱化文字，分组用细分隔线，禁用项降低对比度。 |
| 悬停或键盘移到一行 | 平面 | 使用实色底。键盘焦点另有轮廓。 |
| 已勾选、当前选项、已展开的子菜单入口 | 平面 | 保留浅底色。用勾号或单选标记指明当前值，用箭头指明子菜单路径。 |
| 危险项 | 平面 | 用危险色文字与浅色高亮表达操作性质。 |
| 收起的触发器 | 依控件类型 | 普通按钮沿用凸起材质，ghost 使用平面，选择器沿用字段凹槽。 |
| 展开的触发按钮、按住的菜单项 | 保留原层级 | 展开按钮保留按钮材质，用边缘明暗表达展开；菜单项在悬停底色上轻微变暗，采用浅内描边，不挖出深色凹槽。 |

外壳圆角等于菜单项圆角、内边距和边框宽度之和。Graphite 默认值分别为 6px、3.6px 和 1px。强制配色下用系统轮廓和选中标记表达状态。触屏菜单的行高至少为 40px。
