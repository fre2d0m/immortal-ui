# Blocks 规范与视觉审查

审查范围包括 8 个可安装 Block、3 个规划页、Blocks 目录、演示状态、用法示例和 shadcn 安装产物。对照项目已有的 Graphite 材质规则，检查了页面信息顺序、主要任务路径、浅深色和键盘交互。

| 对象 | 审查发现 | 已调整 |
| --- | --- | --- |
| 目录与场景页 | 计数多处重复，预览标题和页面标题争夺注意力，长页面的安装入口难找。规划页有重复状态说明和装饰序号。 | 中文任务名优先，英文保留供检索。缩紧缩略图留白，对齐同排图文。安装入口可定位到说明并交接键盘焦点。规划页集中呈现示意图和界面结构。 |
| 设备目录 | 搜索、状态筛选和结果数量分散。产品筛选后，状态数量仍对应全站。窄屏表格省略最近活动。 | 搜索、筛选和结果按操作顺序排列。状态数量依据当前关键词和产品计算。窄屏将活动时间并入状态列。快速预览关闭时焦点返回来源。 |
| 设备详情 | 在线状态远离设备标题。每张读数卡重复显示绝对时间和来源，标签在浅色下对比不足。 | 连接状态贴近设备名。关键读数、质量、时效和异常原因优先显示，采样和接收时间放入可展开的来源详情。 |
| 设备参数配置 | 英文标签和控制样式与其他场景不一致。后台回读可能覆盖输入。区间滑块缺少读屏名称。 | 表单按采集连接与温度阈值分区，反馈和保存操作相邻。相同配置回读保留草稿，实际配置变化时可主动载入最新值，切换设备清空旧草稿。两个滑块有独立名称。 |
| 告警处置 | 同一告警的状态和现场条件难以快速区分，确认与清除在长记录之后。 | 队列显示级别、状态和时间。详情明示现场条件，操作放在处置记录上方。确认结束和清除弹窗关闭后恢复键盘焦点。 |
| 遥测历史 | 同单位曲线难靠颜色区分，纵轴只显示极值。部分指标全缺测时仍绘制默认刻度。应用区间可因输入精度被截断。 | 同单位曲线使用不同线型，并补充对齐刻度、可用键盘读取时间的游标及固定表头。无有效读数的单位显示明确状态，查询保留 UTC 时间精度。 |
| 场景与群组 | 树中的数量缺少口径，容易读成含子群组的合计。 | 在树与设备面板都标明直接绑定，选中群组和直接绑定数量提供读屏文本。 |
| 土壤剖面 | 深度标记有按钮材质，读数缺测与选中态难同时辨认。 | 深度标记改为静态标记，缺测同时显示文字与状态点。读数对齐同一深度，主操作指向所选层历史。 |
| 温室控制 | 三张读数卡重复在线和质量状态，观测、模式、设定与执行器的位置分散，趋势与首屏示例读数的时间不同。 | 集中展示一次连接状态和一组观测读数。桌面并列环境趋势与气候控制，执行器和告警独立分区。示例趋势的末点与当前温度一致。 |
| 共用规范 | 警示文字、滑块、信号图和可滚动代码存在对比度或语义问题。 | 警示正文使用由主题派生的高对比文字色。区分范围滑块和采样游标的可读名称。信号图有图形语义，代码可用键盘滚动。 |

## 回归验证

- 使用 Chromium 检查浅色和深色，覆盖 1440、820 和 320 px。逐页检查目录、8 个可安装案例和 3 个规划页。
- 走通设备筛选、分页、快速预览与下钻，遥测查询、失败重试、缺测与 CSV，配置校验、离线、保存失败与恢复，以及告警确认和清除。检查温室自动模式锁定、执行器回读和离线快照。
- 在独立项目用 shadcn 安装八个 Block 与 Graphite，构建并挂载。核对配置刷新与切换设备、跨单位缺测、键盘游标及毫秒级 UTC 区间回传。
- 两种配色的 24 个默认页面和 16 个离线、缺测、表格、校验与对话框状态通过 axe 自动扫描。32 项项目测试、类型检查与生产构建通过。
