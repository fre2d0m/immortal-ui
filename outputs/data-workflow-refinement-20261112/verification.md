## 产品与视觉变化

| 修改前 | 修改后 |
| --- | --- |
| Panel 的展示型标题、圆形身份图标和 24px 四边留白 | 独立工作区，紧凑名称与动作栏，Graphite 材质和控件保持共用 |
| 34px 按钮与 40px 手写切换按钮并列 | 使用共享 Button；桌面实测 34px，触控按钮与图标按钮至少 40×40px |
| 画布、节点、连接、运行记录四个一级入口 | 常驻画布；节点库、大纲和配置按需展开，调试在下方收放 |
| 默认完整可见 2/11 个节点 | 相同 1600px 视口中完整可见 11/11；示例按实际节点坐标组织紧凑拓扑，端口随连接方向适配 |
| 节点技术标识、执行策略和说明占据主位置 | 名称与配置优先，策略与定义折叠；宿主可传专门配置表单；详情使用现有共享 Tabs |
| 运行时切走画布 | 节点呈现实际执行状态，运行行定位对应节点并打开输入输出；耗时由实际起止时间计算 |
| 未完成流程不能保存，误操作没有撤销 | 不完整草稿可保存；执行前校验；增加撤销、重做、复制、导入撤销与按一次拖动恢复 |
| 示例保存无接入 | 展示层在当前浏览器实际保存、恢复草稿；失败给出错误，可导出 JSON 留存 |
| 极长名称占满配置栏 | 节点及侧栏标题保留两行，完整名称保留在可访问名称、DOM 文本与名称输入框中 |
| 安装包包含 Panel 布局文件 | 安装工作区、模型、辅助配置组件及样式，依赖 shared Tabs；不含 Panel 与演示执行器 |

## 验证结果

- `npm run check`：类型检查、61 项测试与生产构建通过，详见 `checks.txt`。其中 15 项工作流测试涵盖固定输入、并发、ALL/ANY、异常、取消、导入、布局与安装闭包。
- `browser-check.mjs`：本机 Chrome 中完成添加、复制、撤销重做、持续拖动撤销、键盘 Tabs、参数 0、表单连线、指针端口连线、JSON 导入/撤销、空白流程构建、保存刷新恢复、测试前校验、放大工作区、菜单、Escape 与焦点恢复。无页面异常。
- 数据核对：18/20/22 °C 产生均值 20、样本数 3，进入归档；24/26/28 °C 产生均值 26，进入复核。气象失败、缺测拒绝、异常出口和取消均检查实际回执；测试过程画布仍可见。
- 独立项目通过官方 CLI 安装 6 个文件（Button、Tabs 与 4 个工作区文件），独立类型检查与构建通过。安装内容与最终 registry 核对一致；CLI 仅移除了模型首行文档注释。构建存在单入口包大于 500 kB 的提示，未进行性能规模声明。
- 独立接入检查保存失败/成功、外部更新后忽略旧运行、跨年 UTC 时间、输入 0 / 输出 false、宿主专门表单、只读与撤销。详见 `installation-checks.json`、`installed-files.json` 和 `install.txt`。
- 深浅主题 12 个主要文字样本最低对比度 5.438:1。检查强制颜色、减少动效、触控模拟、320px 视口和 Theme Studio 20px 字号。长名称完整保留，侧栏标题 60px、配置内容区 401px，整页无横向溢出。详见 `visual-checks.json`、`long-name-checks.json`。
- `docs/` 与已验证构建同步。没有提交、发布或连接真实设备。
