## 验证

- `check.mjs` / `checks.json`：本机 Chrome 实际验证添加、节点/连接大纲、撤销重做、草稿保存、测试/停止状态、画布缩放及展开工作区。18/20/22 的演示输入仍产生 20，并进入未命中分支。没有页面异常。
- 深浅主题三组工具栏的 11 个按钮均为 34×34；触控模拟均至少 40×40。320px 视口、20px 字号无整页横向溢出，提示不超出视口。工作区宽度不超过 420px 时隐藏缩略图，避免与编辑工具栏重叠，保留缩放及显示完整流程。触屏长按只打开提示，松手不执行，随后点击正常操作。
- 提示可悬停、聚焦和移入阅读；Escape 只关闭提示，不关闭当前侧栏或原生展开对话框。展开再收起后提示仍挂载于当前工作区。
- `tooltip-contrast.json`：深浅主题提示文字对渐变两端的最低对比度为 12.576:1。
- `build-checks.txt`：类型检查、62 项测试和生产构建通过。
- `install-checks.txt` / `install-source-match.json`：官方 CLI 更新独立临时项目；本次修改的 3 个安装文件与源文件逐字一致；独立类型检查与构建通过。独立浏览器核对保存中、保存失败/成功、停止等待及展开/收起后的提示。独立项目单入口包仍有超过 500 kB 的构建提示，没有作性能规模承诺。
- `docs/` 与最终构建同步。未提交或部署。

本次是图标入口、提示与既有动作的回归检查；使用固定演示数据，没有接入真实设备或执行服务。触屏为浏览器模拟，未验证物理设备、Safari/Firefox 或读屏软件。
