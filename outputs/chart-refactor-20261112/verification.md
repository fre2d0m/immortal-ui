## 检查入口

- `browser-check.mjs` / `browser-checks.json`：主要图表数据、交互、对比度、重排、触控模拟与边界验证。
- `showcase-check.mjs` / `showcase-checks.json`：目录、Blocks、Theme、温室、土壤剖面、设备详情和首页。
- `fixture.html` / `fixture.tsx`：本地边界验收页面；不进入可安装组件。
- `installation-check.mjs` / `installation-checks.json`：独立安装项目的生产预览。复跑需要先按记录准备临时消费项目并在 4196 端口启动预览；临时目录记录在 `consumer-path.txt`。
- `check.txt`：完整类型检查、61 项测试与生产构建记录。
- `history-dark.png` / `history-light.png`：多单位分图、缺口与逐点读数。
- `history-mobile-*` / `history-large-text-*`、`card-288-*` / `card-505-*`：窄屏与卡片实际宽度。
- `catalog-history-*`、`catalog-*`、`theme-*`、`blocks-soil-profile-*`：展示入口。
- `installed-consumer.png` / `installed-mobile-light.png`：独立消费项目。

初次独立页面的 Grid 列被验收包装器的 505px 固定宽度撑开。将验收页列轨道明确为 `minmax(0, 1fr)` 后重测通过；没有用展示站 CSS 掩盖安装组件问题。`before/` 保留初期截图及失败诊断，不作为最终验收截图。
