# 工作流端点编排验收

本次将添加节点从左侧节点库迁到画布端点，保持 Graphite 材质、字体、共享按钮与 Tabs。未提交或部署。

## 最终行为

- 空流程显示虚线起步节点，点击仅列出宿主提供的触发模板；占位节点不写入流程定义。
- 每个可编辑输入/输出端口提供短引线和圆形加号，悬停放大到 1.12 倍。点击区在编辑缩放 1 下实测为 40×40px；缩放画布时随图形缩放。读屏名称保留节点与端口信息，另有键盘入口。
- 点击加号或拖线到空白画布打开就近选择器。按方向、数据类型、扇入/扇出、重复与循环约束筛选；选择后创建节点与连线，取消不产生任何数据。
- 普通已连接端点插入新步骤并保留前后连接；条件节点明确选择后续出口。并行 out 追加分支；汇合/异常输入追加上游；可连接已有节点。
- 新增、插入与连线作为一个撤销步骤，已有节点位置不变。去掉左侧节点库/大纲及连接表单；保留直接拖线、连线配置与结构问题定位。
- 失败出口按 error 类型验证，不能进入只接收观测数据的处理器；any 仍由宿主明确放宽约束。

最终浏览器全流程在相同源码的独立本地预览快照完成，以避免共享工作区的生成文件更新打断交互。source-hashes.json 核对 4 个安装源文件及演示定义与该预览完全相同。复跑可设置 WORKFLOW_PREVIEW_URL；默认仍指向 127.0.0.1:4177。阶段性截图收在 intermediate/，不作为最终验收证据。

开发服务器在最终浏览器检查期间另记录了一次 `ResizeObserver loop completed with undelivered notifications` 布局观察器通知。该次全流程检查的动作、截图与数据断言均完成，未观察到持续通知或交互中断；脚本里的 `errors: []` 不代表开发服务器所有日志均为空。

目录校验同步改为比对实际声明的组件名称，而非写死数量；保留唯一性、完整安装内容与依赖检查，适应同工作区其他组件的新增。

以上是界面、图结构、安装与固定演示数据的验证。真实 IoT 接入、后台调度/并发执行、真实投递、读屏软件、实体触屏设备及大规模图性能未在本次验收。类型兼容来自宿主声明，不能代替实际消息结构和业务校验。现有保存草稿保留原位置；扩大示例间距只影响恢复示例或用户主动整理布局。
