# 工作流标识与运行结果区验收

日期：2026-11-13。范围：左上身份图标、配置校验入口、当前运行结果的信息组织、共享下划线式 Tabs 的尺寸。保留现有 Graphite 材质及编排交互。

## 产品判断与调整

原来的底栏混合了定义校验、连接数量、配置中的并发上限和运行结果。“调试”实际只展开一张表，输入输出还在右侧配置栏，不能支持连续排错。它不等同于执行历史、单步执行或失败重放。

| 原实现 | 最终实现 |
| --- | --- |
| 左上裸图标 | 40px 圆形 `surface-control` 底座、16px 图标，静态身份标识，无交互反馈；不改变工作区整体布局。 |
| 底栏同时放结构就绪、连接数、并发数和调试 | 配置校验移到顶部图标入口；底部仅保留运行结果摘要。并发上限留在流程设置和并行节点摘要。 |
| “调试”与“本次运行”重复显示状态和收起操作 | 一个折叠条展示结果状态和总耗时；运行标识、完整 UTC 起止时间在按需展开的运行详情中。 |
| 逐节点宽表，选择后到远处配置栏看数据 | 左侧节点导航、右侧就地核对输入/输出/执行信息；定位画布和查看配置有独立动作。配置侧栏、右键入口都打开同一个结果区。 |
| 无排错优先级 | 默认优先失败节点、再执行中、最后完成的成功节点；可只看失败节点，手动选择不会被流式更新切走。 |
| 取消时清掉已收回执 | 保留最后回执，说明停止等待并不代表后台停止。新的受控回执到来时移除过期的本地取消/请求提示。 |
| 下划线 Tab 在触控下实测 26px | 在共享 Graphite 的 line 变体规则中修复高度，触控至少 40px；不改变默认 Tab 的选中材质规则。 |

设计依据是任务分层，非复制另一产品外观：

- [n8n 执行类型](https://docs.n8n.io/workflows/executions/manual-partial-and-production-executions/)区分编辑器手动测试、部分执行与生产触发。
- [n8n 单工作流执行历史](https://docs.n8n.io/workflows/executions/single-workflow-executions/)用于检索历史执行。
- [n8n 执行调试](https://docs.n8n.io/workflows/executions/debug/)将已保存的执行数据带回编辑器复现。

这些职责需要不同的数据和动作。当前 Block 只承诺定义编排与匹配当前定义的一次回执检查，没有添加虚假的历史、日志、重放或单步按钮。
