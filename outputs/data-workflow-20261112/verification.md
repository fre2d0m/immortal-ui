# 数据处理工作流验收 · 2026-11-12

## 交付

- 新增可安装 `data-workflow` Block，使用 `@xyflow/react` 12.12.1；入口 `#/blocks/data-workflow`。
- 新增「数据处理」分类，包含交互预览、由同一演示定义生成的静态目录示意、安装与接口说明。
- 11 种节点职责、18 个展示层模板，覆盖触发、多源输入、处理、条件、并行、汇合、分发与失败归档。
- 受控编辑、节点配置、结构校验、JSON 导入导出、展开工作区、节点/连接列表和执行追溯。
- 运行记录绑定定义签名，修改配置、外部更新或取消后不接收旧结果；布局改变不改变运行口径。
- 定义、局部 CSS 与 React Flow 安装依赖一起交付。演示观测、模板和内存执行器不进入安装包。

## 验证结论

| 维度 | 证据与结论 |
| --- | --- |
| 类型、测试、构建 | 类型检查通过；55 个 Node 测试全部通过，包含 15 个工作流测试；生产构建通过。见 `tests.txt`、`build.txt`。 |
| 已知输入 | 18/20/22 °C → 均值 20 °C、3 个样本、常规归档；24/26/28 °C → 26 °C、人工复核。降雨 mm 不与水温混算。 |
| 缺测与失败 | 缺测剔除后 2 个样本、均值 20 °C；配置拒绝无效输入时，错误进入失败归档。HTTP 模拟失败阻断 ALL 汇合。 |
| 并发 | 捕获同时活跃的两个源节点；ALL 开始时间不早于两个来源的结束时间；上限 1 时无重叠。ANY 可在另一输入失败时继续，但保留整个运行的失败。 |
| 数据语义 | 0、负值、单点、常量、跨年窗口、混合单位、原始输入与转换溯源、缺测、超时、重试和取消均有断言；没有模型结果补造。 |
| 浏览器交互 | Chrome 157.0.8103.52：鼠标拖动/连线、键盘选择与移动、配置、连接表、添加/移除、JSON 往返、坏文件拒绝、试运行与取消通过。 |
| 视图与可访问入口 | 深浅主题、320px 视口、Theme Studio 的 20px 字号、长名称、触控模拟、Escape 关闭展开工作区及焦点恢复通过。无整页横向溢出，宽表局部滚动。 |
| 默认主题对比度 | 实际计算节点文字、元信息、配置文字与画布提示；最低 4.883:1。连线箭头跟随主题，强制颜色下使用 CanvasText。此项不是完整无障碍认证。 |
| 安装边界 | 从本地 Registry 用 shadcn CLI 安装到独立临时项目；文件、React Flow、Graphite 及按钮依赖完整，独立类型检查和构建通过。保存失败/成功、只读、跨年 UTC 时间、输入 0 / 输出 false、外部更新淘汰旧结果通过。 |
| 实际业务接入 | 未连接真实设备、接口、调度、数据库、消息或模型；试运行是明确标记的固定演示。 |
