# 图表样式与交互精修 · 2026-11-13

本轮继续使用 Recharts，定制实际组件与共享主题。没有新增图表引擎，也没有改变采样、质量、聚合与尺度契约。所有验证使用演示输入。

| Before | After |
| --- | --- |
| 默认蓝绿配色，线条与网格层级接近 | 默认蓝 / 琥珀色拉开区别；图线 2.5px，图例聚焦时对应图线 3px，其余弱化。网格 1px、低对比虚线；事件使用中性点线。 |
| 图例独占左侧一行，重复指标名称 | 图例在图表顶栏靠右。共同名称提为组标题，图例保留差异部分；完整名称仍用于可访问名称和 tooltip。窄屏重排，40px 点击区保留。 |
| 读数常驻图下，逐点按钮与说明占用大量高度 | 桌面浮层显示实际时间、序列、单位及提供的质量；缺测与无此时刻采样分开。悬停可读、移入可停留、点击保留、Esc / 关闭按钮 / 外部点击关闭。 |
| 键盘操作依赖下方滑块 | 图表本身可聚焦，左右键、Home、End 逐点读取；点击后焦点留在图表容器，避免 SVG 内部焦点环围住多个选中点。数据表继续提供等效读取路径。 |
| 窄屏浮层遮住大部分曲线 | 小于等于 32rem 的容器将选中读数排在图下，仅交互时出现；图表仍完整可见。 |
| 查询摘要与结果操作分占两行 | 视图切换、筛选和导出合并为一行；筛选展开后保留完整表单，查询完成后焦点返回筛选按钮。 |
| 范围、样本数、缺口规则、事件与操作说明散落图下 | 收进图表信息入口；时间与单位保持可见。日期端点各自保持完整，长时区仍可换行。 |
| 概览卡片重复显示范围、极值、缺测说明和口径折叠区 | 默认留下概览、范围、曲线和时间，极值与口径移到范围旁的信息浮层；越界与无效配置仍显示。 |
| 共享依赖与图表样式 | Metric / Indicator 显式声明 Radix 依赖；展示页、安装包和 Theme 导出共用 Graphite 样式。 |

## 验证

- [类型、测试、生产构建](check.txt)：64 项测试通过，0 失败。
- [独立安装更新](install.txt)、[消费工程构建](consumer-build.txt)：通过。最终安装页面实际点击后焦点为图表容器，方向键读取到 2026-01-01 00:01:00 的 10.0 °C，未捕获页面 error 日志。
- [浏览器记录](browser-checks.json)：指针悬停、tooltip 可移入、点击保留、外部点击与 Escape 关闭；图例显隐及聚焦强调；隐藏序列时共用尺度保持不变。
- 可手算跨年案例：第 1 分钟读取 A=10.0 °C，B 为“无此时刻采样”；第 3 分钟 A 为“缺测”。零值、单点、常量、空、无效、极端值及不同单位分别检查。插入更早记录后保留已选时刻，删除所选记录后出现明确提示。
- 查询仅 A 后，表格和 CSV 都为 5 条，包含 0、10、缺测、−10、20；去重后没有旧值 999。查询结束焦点返回筛选按钮。
- 320px 深浅主题、20px 字号、极端有限数值检查未出现整页横向溢出。Metric、Indicator、温室和 Theme 在加载图表后记录了桌面布局。未逐一重新验收这些页面的全部业务操作。
- 实际面板背景上的默认图线最小对比度：浅色 4.80:1，深色 6.56:1；辅助文字分别为 5.49:1、5.85:1。这不覆盖任意自定义配色或聚焦时主动弱化的其他序列。
- 强制颜色与减少动效模拟下，线、标记、tooltip 保留可见系统色；模拟设置和临时视口尺寸已恢复。

限制：内置浏览器不支持触摸事件派发，本轮未完成真实触控验证；未做完整读屏、多浏览器、高频或大数据量测试，也未接入真实设备。截图、单元测试与业务接入是不同的证据。

交互参考：[Recharts Tooltip](https://recharts.github.io/en-US/api/Tooltip/) 与 [W3C 悬停/聚焦内容要求](https://www.w3.org/WAI/WCAG22/Understanding/content-on-hover-or-focus.html)。动态采样浮层由 React 控制，图形布局与指针命中继续使用 Recharts；信息入口使用现有 Radix Popover。
