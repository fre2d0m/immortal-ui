# 单图标操作按钮的圆形规范

日期：2026-11-13。

## 判断与改动

独立图标操作没有文字长度约束，等宽高与圆形轮廓符合当前 Graphite 的图标底座、端点和轻微凸起材质。原来的 6px 是文字按钮共用的基础圆角，缺少对单图标操作的形态区分。此变更位于共享 Graphite 来源，不在四个工作流按钮上单独覆盖。

| Before | After |
| --- | --- |
| 独立 `icon / icon-xs / icon-sm / icon-lg` 都继承 `--button-radius`，默认 6px | 共享 `graphite.css` 对这些尺寸统一使用 50% 圆角；尺寸、图标和不同权重的材质沿用原规范。普通、悬停、按下、焦点、禁用及展开状态保持圆形。 |
| 图标按钮在 `control-row` 中可随较高的 Tab 轨道只拉伸高度，变成椭圆 | 独立图标按钮保留自身尺寸并垂直居中；与输入框配套的加减按钮同时匹配输入框宽高。文字按钮、输入框、选择器及 Tab 轨道继续按行对齐。 |
| 工作流画布编辑和缩放工具栏使用基础按钮圆角加 4px 的外壳 | 两个浮动工具栏使用胶囊形外壳，与内部圆形按钮形成同心关系。 |
| Theme 的“胶囊形按钮”未交代作用对象 | 标注为“文字按钮与按钮组使用胶囊形”；独立图标按钮的圆形不依赖此开关。 |
| 基础规范和 README 将按钮圆角混写 | 明确独立图标、文字按钮、连体按钮组以及组合行的规则。连体按钮中间分段继续保持直边，端部沿用组外壳圆角。 |
