# 工作流图标工具栏按数量分组

日期：2026-11-13。

同一功能组内，1–2 个图标动作独立呈现，3 个及以上共用紧凑胶囊外壳。先按职责分组；内部动作继续保持各自的主次材质、圆形轮廓、无障碍名称及键盘行为。

## 改动

| Before | After |
| --- | --- |
| 撤销与重做是共同胶囊内的两个 ghost 图标 | 移除共同外壳，两个动作分别使用共享 Outline 圆形材质；禁用、可用、悬停及焦点保持各自的操作范围。 |
| 顶部、历史、缩放的外壳分别由页面样式写死 | `WorkflowToolbar` 共用 `wf-icon-toolbar`，CSS 根据实际直接子级图标按钮数量决定外壳。第三个按钮出现时成组，无需 React 子元素计数或额外状态。 |
| 顶部四个操作始终分散；宿主提供不同能力时没有成组规则 | 四个或三个动作共用胶囊，移除可选保存/运行能力后剩余两个动作独立。禁用不影响数量；读数、提示和菜单弹层不计入。 |
| 窄屏顶部操作行铺满整行，展开按钮靠最右 | 外壳紧贴动作；空间不足时整组换行，避免大面积空白或把一个组拉散。 |
| 基础文档把编辑和缩放工具栏一律描述为胶囊 | 基础规范与工作流说明明确职责、数量和动态判断规则；两个连接操作独立，缩放百分比保留为读数。 |

## 验证

- `check.mjs` 在源码隔离预览和独立安装消费者各通过 4 组检查，见 `checks.json` 与 `installed/checks.json`：深浅主题下 4→3→2→3→4 动态切换，保存禁用期间分组稳定，缩放读数不计数，菜单开关，左右方向键循环，实际名称编辑与撤销/重做，强制配色，390px / 20px 字号 / 触控模拟。
- 撤销与重做容器边框 0、透明背景、无投影；按钮分别为 Outline 圆形。顶部 3–4 个与缩放 3 个按钮的容器使用 1px 边框和公共外壳。
- 触控按钮至少 40×40px；窄屏顶部组内按钮同排、外壳宽度小于 230px，页面未横向溢出。缩放栏的百分比继续正常显示。
- 保留现有 Radix 工具栏与提示，不叠加另一套方向键或焦点管理。菜单打开时背景工具栏会被无障碍树暂时隐藏；几何检查使用 DOM 选择器读取背景外壳，键盘检查等待 Radix 完成异步焦点移动。
- 已人工查看深浅主题、独立按钮、成组按钮及窄屏菜单截图。独立消费者通过 shadcn CLI 更新，关键 CSS 与工具栏源文件和仓库一致；消费者类型检查和构建通过。
- 最终 `npm run check` 通过：类型检查、84 项测试、生产构建。第一次并发检查中的 npm test 启动进程曾意外退出（`check-aborted.log`）；关闭验收服务后串行重跑通过。没有修改代码规避失败，也没有新增仅复述 CSS 实现的单元测试。
