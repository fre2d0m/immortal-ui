# 土壤水分分析：视觉重构与复审

日期：2026-11-13。范围：可安装的 `soil-water-explorer`、共享绘图、色阶、网站及静态产物。数据为明确标记的可重复演示场景，未接真实设备。

## 设计决策

| 复审对象 | 修改前 | 最终处理 |
| --- | --- | --- |
| 配色 | 通用主题色同时承担多个业务含义 | 有序矿物绿热图；深度分类色与稳定线型；气象、故障、灌溉独立语义色，深浅主题分别校准 |
| 视觉重心 | 热图占用主要高度，比较曲线较扁 | 主分析区按热图 38%、曲线 62% 分配；气象、Kc、事件为紧凑关联轨道 |
| 线条与图例 | 曲线权重接近，需来回找图例 | 普通曲线 2.2px、聚焦 3px、其他曲线 1.1px；六条以内且宽度允许时末端直标深度；读数行兼作可聚焦图例 |
| 数值读数 | 重复标题、日期挤占高度 | 公共时间置顶，单位与质量保留；主值右对齐；实际采样时间不同时仍单独显示 |
| 事件关联 | 各图分别高亮，视觉较碎 | 单一时间带贯穿所有轨道，真实边界；瞬时事件保留线/菱形，未知结束时间不补造边界 |
| 同屏布局 | 已有紧凑工作区，但局部仍拥挤 | 五层共用底部时间尺；右侧固定读数，20 层时列表局部滚动；窄屏读数浮层；不靠缩小所有文字维持同屏 |
| 范围与可比性 | 参考范围使正常波动过于扁平 | 明示“观测范围 / 参考范围”；两种范围均来自完整数据，切换时间窗、深度或事件不改变尺度 |

保持原始数据形状、缺口与质量判断；没有平滑、插值或改变统计口径。ECharts 风格配置参考其[官方说明](https://echarts.apache.org/handbook/en/concepts/style/)。

## 数据与交互验证

浏览器证据见 `browser-checks.json`，实际下载见 `known-export.json`。

- 年度场景：20 深度、175,056 条接收记录、7,300 个日分箱热图单元；全选 20 层后图层高度保持不变，读数列表局部滚动。
- 手工案例：8 小时跨年窗口，实际验证 0、−5、空值、未报告时隙、70 越界且存疑、常量 25、单点 15、无效记录。主值、游标、原始表格与数据切换一致。
- 核对案例的真实导出仅含所选深度的 `[0,10,null,-5,70,20]`、3 组气象/系数、4 个事件，窗口保持 `[from,to)`；未报告时隙未补零。
- 同一组 21.6 / 26.7 读数在两种纵轴范围中位置随尺度正确变化。从浏览器游标坐标反算的值误差小于 0.06，见 `geometry-check.json`。
- 事件定位到 52 小时通道故障后，仅一条跨层时间带；50 cm 显示故障空值，其他深度仍为各自观测；点击后右方向键从当前事件时刻推进一小时，没有跳回窗口起点。
- 原始数据表、深度选择、空态、固定读数与 Escape 关闭浮层已检查。

## 视觉复审

- 1280×720：独立生产预览的图表与右侧读数外层均为 456px，外层没有额外纵向溢出。五层与时间导航同屏；见 `installed-final.jpg`。
- 375×812：展开工作区宽 349px、高 786px，均与自身滚动尺寸一致；图表高 530px，无额外纵向滚动，五层全部可见；页面无横向溢出。见 `narrow-final.jpg`。
- 375px、根字号 20px、超长标题、浅色主题：图例自然增高且不与热图重叠；保留最小绘图高度，允许工作区局部滚动至事件层。见 `large-text-light.jpg`。该条件不声称所有图层无需滚动。
- 深浅主题文字和语义标签对实际卡片背景最低 4.59:1；范围细线合成后最低 3.41:1。连续热图六阶亮度单调。详细计算见 `contrast.json`；不外推到调用方任意自定义颜色。
- 粗指针模式下可见操作入口均不小于 40px，三项 Tab 高度均为 40px。浏览器不支持本次触控事件注入，未将这一检查写成真实触屏手势验收。
- 复审发现并修正了大字号图例重叠、粗指针 Tab 高度不足、浅色冻融标签对比度不足、事件定位后键盘游标不同步。最终图像见 `preview.jpg`，浅色和全年 20 层检查分别见 `light-1280.jpg`、`annual-20-depths.jpg`。
