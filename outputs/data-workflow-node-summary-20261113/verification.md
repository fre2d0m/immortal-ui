# 工作流节点摘要与视觉规范验收

日期：2026-11-13。预览：`http://127.0.0.1:4177/#/blocks/data-workflow`。

| 修改前 | 修改后 |
| --- | --- |
| 普通节点取第一个参数，条件取前两个值用点拼接，无参数时回退描述 | 明确 `getNodeSummary` 契约：适配器按稳定参数 key 从当前配置生成字段摘要或比较表达式；没有适配器时只显示真实参数数量 |
| 聚合只显示指标，无法判断方法和窗口 | 指标、方法、固定窗口分别呈现；固定窗口时长从真实起止配置计算，精确时间仍可在配置中核查 |
| 条件显示“大于等于 · 21” | 比较对象、运算符、阈值分开提供并组成表达式；不猜单位 |
| 并行描述“同时执行”，未表达调度限制 | 展示实际输出分支数量和全局并发上限；汇合显示实际输入数量与等待策略 |
| 节点高度随端口数量或小字换行变化 | 默认字号所有节点 232×168，标题区 58、摘要区 62；值按字段对齐，长值省略但可在配置中核查 |
| 同侧端口等分高度，端口越多节点越高 | 同侧端口按 42px 间隔围绕中心排列，四个同侧端口也保持节点原有高度 |
| 仅有回执的节点增加运行行 | 当前运行中的节点统一增加独立结果行；未收到该节点回执时明确显示“未提供记录” |
| 新增/复制仍沿用旧尺寸偏移 | 新增按画布坐标居中，复制按实测高度留出 32px 间距；定位、目录静态示意与示例间距同步 |

## 验证

- `build-checks.txt`：类型检查、64 项测试和生产构建通过。新增数据验证覆盖参数重排、方法/窗口修改、0、负值、false、空文本、缺配置、无效数字及未知适配器回退；摘要生成不修改执行定义。
- `check.mjs` / `checks.json`：实际浏览器核对 11 个节点在深浅主题中同宽同高；修改条件和撤销即时更新；导出后反转所有参数数组并重新导入，摘要内容与顺序保持不变。
- 手工可复核输入：将窗口改为 00:10–00:20 UTC、方法改为最大值，摘要显示“最大值 / 固定窗口 10 min”；实际输出为 22 °C、样本数 2，来自窗口内 20/22 的观测。没有连接生产接口。
- 将条件的四个端口放在同一侧，实际间距为 42px，节点高度仍为 168px。
- 运行期间节点高度统一为 200px；20px 字号及长标题、长目标下统一为 179px。320px 视口无整页横向溢出。完整目标可通过键盘大纲和触屏大纲进入配置查看，无障碍名称保留完整值。
- 深浅主题 10 个类型、字段、值与表达式文字样本最低对比度为 5.438:1，见 `contrast.json`。
- `geometry-actions.json`：放大画布后添加节点仍按中心定位；复制节点考虑当前实测高度，不覆盖原节点。
- 独立临时项目通过官方 CLI 更新、类型检查与构建；4 个安装文件与最终源文件一致，CLI 仅省略模型文件首行说明注释，见 `install-source-match.json`。默认回退和宿主表单更新在独立浏览器检查通过；部分节点回执缺失时明确显示“未提供记录”，节点高度仍一致，见 `installed-checks.json`、`partial-run.json`。
- 独立单入口构建仍提示包超过 500 kB；没有作规模或性能承诺。`docs/` 与最终构建同步。未提交或部署。

规范见 `design-notes/data-workflow.md` 的“节点的关键配置摘要”。本次浏览器验证使用 Chrome 和触屏模拟，未验证物理触屏、Safari/Firefox、读屏软件或真实执行服务。
